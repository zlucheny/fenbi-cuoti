【政治理论·毛中特 / 党的基本知识 / 党章党纪】第531题（答案C，难度5）
题干：2020年3月9日，中共中央办公厅发布《党委（党组）落实全面从严治党主体责任规定》，根据该规定，党组（党委）应当加强对本单位（本系统）全面从严治党各项工作的领导。在加强党的建设方面，下列理解不准确的是：
选项：A.支持纪检监察机关履行监督责任，一体推进不敢腐、不能腐、不想腐 B.持续整治“四风”特别是形式主义、官僚主义，反对特权思想和特权现象 C.把党的思想建设摆在首位，坚定政治信仰，强化政治领导，提高政治能力，净化政治生态 D.党组（党委）带头遵守党内法规制度，严格落实党内法规执行责任制
解析：本题考查政治常识。
A项正确，根据《党委（党组）落实全面从严治党主体责任规定》第七条第七款规定：加强党的纪律建设，履行党风廉政建设主体责任，支持纪检监察机关履行监督责任，一体推进不敢腐、不能腐、不想腐。
B项正确，根据《党委（党组）落实全面从严治党主体责任规定》第六条第六款规定：持之以恒抓好党的作风建设，落实中央八项规定精神，持续整治“四风”特别是形式主义、官僚主义，反对特权思想和特权现象，密切党同人民群众的血肉联系。
C项错误，根据《党委（党组）落实全面从严治党主体责任规定》第六条第三款规定：把党的政治建设摆在首位，坚定政治信仰，强化政治领导，提高政治能力，净化政治生态，始终在政治立场、政治方向、政治原则、政治道路上同党中央保持高度一致。
D项正确，根据《党委（党组）落实全面从严治党主体责任规定》第七条第八款规定：带头遵守党内法规制度，严格落实党内法规执行责任制，建立健全本单位（本系统）党建工作制度，不断提高制度执行力。
本题为选非题，故正确答案为C。

【政治理论·新思想 / 新思想总论】第534题（答案D，难度7）

【政治理论·马克思主义 / 马克思主义哲学 / 唯物史观】第558题（答案D，难度7）
题干：习近平总书记指出，从严监督执纪是党的自我革命的利器，对违纪违法问题必须坚决处理。要把党内监督和人民监督结合起来，重视发挥群众监督、舆论监督“前哨”作用，推动各类监督贯通协调。从马克思主义哲学角度看，未体现的哲理是（    ）。

B项正确，联系的客观性指事物的联系是不以人的意志为转移的客观存在（如监督形式之间的关联由监督本质决定）；联系的多样性指事物的联系具有多种形式（如党内监督与群众监督存在直接协同的关联，舆论监督通过社会舆论间接作用于党内监督，而各类监督形式与党的建设之间存在本质的、必然的联系）。题干中“把党内监督和人民监督结合起来，重视发挥群众监督、舆论监督‘前哨’作用”，既承认了联系的客观性，又利用了联系的多样性，通过多种形式协同强化监督效果，遵循了联系的客观性和多样性原理。
C项正确，人民群众是历史的创造者，是社会物质财富和精神财富的创造者，是社会变革的决定力量。发挥人民监督作用，依靠人民的力量推进党的自我革命，体现了党坚持群众观点和群众路线，相信人民群众，依靠人民群众，自觉接受人民群众的监督。

【政治理论·马克思主义 / 马克思主义哲学 / 唯物史观】第559题（答案D，难度4）

【政治理论·马克思主义 / 马克思主义哲学 / 唯物史观】第560题（答案A，难度7）
题干：从马克思主义哲学角度理解毛泽东的“歌未竟，东方白”，下列表述正确的是（    ）。

解析：本题考查马克思主义。
“歌未竟，东方白”出自毛泽东的《贺新郎·读史》，意思是歌还没有唱完，东方已经破晓，曙光初现。该词创作于1964年，创作背景是1963年新中国在战胜暂时的经济困难后，显现出勃勃生机。
A项正确，“歌未竟”表明人类社会还在因生产力和生产关系的矛盾而不断变化发展，“东方白”代表新中国诞生，中国人民从黑暗的旧社会进入光明的新社会，体现了社会发展是一个由低级向高级不断前进的过程。
B项错误，马克思主义唯物史观指出人民群众在历史发展过程中具有主体地位和决定性作用，强调人民群众是历史的创造者。但是题干没有体现人民群众的重要性。
C项错误，社会存在指社会的物质生活过程，其核心是物质资料的生产方式。社会意识指社会的精神生活过程。社会存在决定社会意识，社会意识反作用于社会存在。但是题干没有体现社会存在和社会意识的关系。
D项错误，矛盾的特殊性是指具体事物所包含的矛盾及每一个矛盾的各个方面都有其特点。具体问题具体分析是指在矛盾普遍性原理的指导下，具体地分析矛盾的特殊性，并找出解决矛盾的正确方法。但是题干没有提到矛盾的特殊性。
故正确答案为A。

选项：A.人的本质是社会关系的总和，是自然属性和社会属性的统一 B.人民群众是人口数量上的大多数，即广大劳动者 C.历史的主体是推动历史发展前进的人 D.任何历史人物的出现，都体现了必然性和偶然性的统一
解析：本题考查马克思主义。
A项正确，马克思批判了旧唯物主义把人的本性、本质归结为人的吃、喝、穿、性行为等自然属性的观点，认为人的本质是社会关系的总和，是自然属性和社会属性的统一。
C项正确，B项错误，人民群众是一个历史范畴，包含三层内容：一是从人口的数量上是大多数，而不是少数人，如《共产党宣言》中讲的“绝大多数人”。二是从质上是推动历史发展前进的人。三是以劳动者为主体，包括进步阶级和知识分子。
D项正确，历史人物是实现一定历史任务的主要发起者、组织者和领导者，这其中既包括杰出人物，也包括反面人物。任何历史人物的出现，特别是杰出的政治人物的出现，都体现了必然性和偶然性的统一。
本题为选非题，故正确答案为B。

【政治理论·马克思主义 / 马克思主义哲学 / 唯物史观】第562题（答案B，难度5）
题干：发展新质生产力，必须进一步全面深化改革，形成与之相适应的新型生产关系。要深化经济体制、科技体制等改革，着力打通束缚新质生产力发展的堵点卡点，建立高标准市场体系，创新生产要素配置方式，让各类先进优质生产要素向发展新质生产力顺畅流动，这最直接体现了马克思主义的哪些基本观点？
①生产关系必须与生产力发展要求相适应，才能促进生产力发展
②经济基础的变更必然引起上层建筑的变革，并决定其变革方向
③生产关系对生产力发展具有决定作用
④改革是社会主义社会发展的直接动力
选项：A.①② B.①④ C.②③ D.②④
解析：本题考查马克思主义。
①正确，生产力和生产关系的相互作用构成了生产方式的矛盾运动，这一矛盾运动中，贯穿着生产关系一定要适应生产力发展状况的规律，这条规律是不以人的意志为转移的客观规律，是历史发展的根本规律。新质生产力作为生产力的新发展形态，需要与之相适应的新型生产关系。题干中“形成与之相适应的新型生产关系。要深化经济体制、科技体制等改革，着力打通束缚新质生产力发展的堵点卡点”体现了这一观点。
②错误，经济基础的性质决定上层建筑的性质，有什么样的经济基础就有什么样的上层建筑。经济基础的变更必然引起上层建筑的变革，并决定其变革的方向。选项表述正确，但题干中主要强调的是生产关系与生产力的关系以及改革对生产力发展的作用，并未涉及经济基础变更引起上层建筑变革的相关内容。
③错误，生产力决定生产关系，生产力的产生、性质、水平和发展要求决定生产关系的产生、性质和状况等。生产关系对生产力具有反作用，生产关系适合生产力发展要求，就会推动社会生产力的发展，当生产关系不适合生产力发展的要求时，它就会阻碍生产力的发展。故“生产关系对生产力发展具有决定作用”的说法错误。
④正确，恩格斯指出：“所谓‘社会主义社会’不是一种一成不变的东西，而应当和任何其他社会制度一样，把它看成是经常变化和改革的社会。”题干中“深化经济体制、科技体制等改革，着力打通束缚新质生产力发展的堵点卡点”体现了通过改革来推动新质生产力的发展，进而推动社会主义社会的发展。
故①④说法正确。
故正确答案为B。

B项正确，《马克思主义基本原理（2023年版）》第二章“实践与认识及其发展规律”中提到：“第一，实践是认识的来源。认识的内容是在实践活动的基础上产生和发展的。人们只有通过实践实际地改造和变革对象，才能准确把握对象的属性、本质和规律，形成正确的认识，并以这种认识指导人的实践活动······离开实践的认识是不可能产生的。一切真知都是从直接经验发源的。一个人知识的获得，不外直接经验和间接经验两部分。就知识的本源来说，任何知识都不能离开直接经验······从根本上说，实践是认识的源头活水。要想成就一番事业，不仅要努力学习，而且要潜心实践。”
D项正确，《马克思主义基本原理（2023年版）》第二章“实践与认识及其发展规律”中提到：“第一，认识世界的目的是改造世界······在马克思主义看来，理论作为从感性认识到理性认识飞跃的产物，对行动起到重要的指导作用。没有革命的理论就没有革命的运动，没有正确的理论就没有正确的行动······理性认识回到实践的过程，既是理论指导实践的过程，又是理论实现自身的过程。”先导作用是指认识对实践的导向作用，属于第二性的指导作用，是认识对实践能动反作用的具体表现。
本题为选非题，故正确答案为A。

【政治理论·马克思主义 / 马克思主义哲学 / 认识论】第577题（答案C，难度4）
题干：在现代教育中，许多教育者认为，教育不只是知识的传授，更是激发学生内在潜力，培养其解决问题和创新思考能力的过程。这种教育观念最能体现以下哪一马克思主义哲学原理？
选项：A.对立统一的观点 B.事物的质和量的辩证关系 C.认识和实践的辩证统一 D.两点论和重点论相统一的观点
解析：本题考查政治常识。
A项错误，对立统一规律揭示，任何事物以及事物之间都包含着矛盾性，事物矛盾双方的统一性与斗争性推动事物的运动、变化和发展。选项哲学原理和题干内容无关。
B项错误，事物的质和量的辩证关系主要描述的是事物发展过程中量积累到一定程度会引起质的变化。选项哲学原理和题干内容无关。
C项正确，实践是认识的基础，也是检验真理的唯一标准。人们只有通过实践，才能获得对客观世界的认识。同时，认识对实践具有指导作用。现代教育强调教育不只是知识的传授，更是激发学生内在潜力，培养其解决问题和创新思考能力的过程，这正是基于认识必须与实践相结合的观念。教育不只是简单地传递信息或者知识，而是要引导学生将所学知识运用于实践中，激发他们解决问题的能力和创新思维，使他们能够更好地适应和改造世界。这种教育观念体现了认识和实践的辩证统一原理。
D项错误，两点论和重点论相统一的观点是马克思主义的一个重要分析工具，它主张在分析问题时，要兼顾事物的一般性和特殊性（两点论），同时，也要找出事物发展变化的关键（重点论）。选项与题干无直接关联。
故正确答案为C。

【政治理论·马克思主义 / 马克思主义政治经济学 / 商品经济】第578题（答案B，难度6）
题干：关于马克思主义政治经济学，下列说法正确的有（    ）。
①劳动二重性理论是理解马克思主义政治经济学的枢纽
②单位商品的价值量与生产该商品的社会必要劳动时间成正比
③商品的价格由价值和供求关系共同决定
④抽象劳动的凝结形成商品的价值
⑤具体劳动是商品使用价值的唯一源泉
选项：A.2项 B.3项 C.4项 D.5项
解析：本题考查政治常识。
①正确，劳动二重性指的是具体劳动和抽象劳动这两重属性。具体劳动是人们在一定的具体形式下进行的劳动。抽象劳动是撇开一切具体形式的无差别的人类劳动。劳动二重性理论是马克思的重大贡献，是理解马克思主义政治经济学的枢纽。
②正确，商品价值是由生产该商品的社会必要劳动时间决定的。单位商品的价值量与生产该商品的社会必要劳动时间成正比，与社会劳动生产率成反比。
③错误，商品的价格是由价值决定的，并受供求关系的影响。
④正确，商品的二因素（商品的使用价值和价值）是由生产商品的劳动二重性决定的。具体劳动创造商品的使用价值，抽象劳动的凝结形成商品的价值。
⑤错误，具体劳动和自然物质共同构成商品使用价值的源泉。
故①②④表述正确，共3项。
故正确答案为B。

【政治理论·马克思主义 / 马克思主义政治经济学 / 商品经济】第579题（答案D，难度4）
题干：关于马克思主义政治经济学，下列说法正确的是：
选项：A.商品的价值量是由生产该商品所需的个别劳动时间决定的 B.货币的价值尺度职能是通过实际的物质交换来实现的 C.具体劳动和抽象劳动是不同商品生产过程中的不同劳动 D.具体劳动创造商品的使用价值，抽象劳动形成商品的价值
解析：本题考查马克思主义。
A项错误，商品的价值量是指商品价值的大小，是由生产商品的社会必要劳动时间决定的。社会必要劳动时间即在现有的社会正常的生产条件下，在社会平均的劳动熟练程度和劳动强度下制造某种使用价值所需要的劳动时间。
B项错误，货币的价值尺度职能，是指以自身价值作为尺度来衡量其他商品的价值。货币执行价值尺度职能，不需要现实的货币，只需要观念上的货币，不需要通过实际的物质交换来实现。
C项错误，具体劳动和抽象劳动，是生产商品的同一劳动过程的两个方面，而不是两种劳动或两次劳动。具体劳动说明的是劳动是什么样的，是怎样进行的；抽象劳动说明的是劳动的量的多少，劳动时间的长短。
D项正确，具体劳动是指人们在一定的具体形式下进行的劳动，体现着人和自然的关系，生产出各种各样的使用价值。抽象劳动是指撇开一切具体形式的无差别的一般人类劳动，即人的体力和脑力的消耗。抽象劳动形成商品的价值。
故正确答案为D。

【政治理论·马克思主义 / 科学社会主义】第582题（答案D，难度3）
题干：在十月革命的影响下，1919年五四运动之后，中国无产阶级开始以独立的政治力量登上历史舞台，（    ）。与之同时。马克思主义在中国得到广泛传播，逐步成为中国革命的指导思想。
选项：A.成为革命的主力军 B.由自发阶级转变为自在阶级 C.成为革命的预备队 D.由自在阶级转变为自为阶级
解析：本题考查马克思主义。
A项错误，农民占中国人口的绝大多数，是帝国主义和封建势力的主要压迫和剥削对象，具有强烈的反抗精神，是中国革命的主力军和无产阶级最可靠的同盟军，而非无产阶级成为革命的主力军。
B项错误，D项正确，自在阶级（又称自发阶段）是指无产阶级对资本主义社会的认识还处在感性阶段，没有认识到自己受剥削受压迫的真正原因，没有觉悟到资本家和工人队伍之间的整个阶级对立，不了解自己的阶级地位和历史使命，斗争是分散的、自发的，仅限于经济要求。自为阶级则是指无产阶级在理性认识的基础上，理解了资本主义社会的本质及其剥削关系，并认识到自身的阶级地位和历史使命。自为阶级的工人开始有组织地进行斗争，以马克思主义理论为指导，形成了自己的政党和革命纲领，斗争也从分散的、自发的形式转变为自觉的、有组织的阶级斗争。五四运动之后，中国无产阶级开始以独立的政治力量登上历史舞台，由自在阶级转变为自为阶级。

故正确答案为D。
